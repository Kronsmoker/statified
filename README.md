**StatifiedMLB** is a sports data analytics application designed to help users make data-driven evaluations of MLB games. Users can select the statistics and factors they believe are most important—such as starting pitching, bullpen performance, recent team form, home/away splits, rest days, and other advanced metrics—and StatifiedMLB uses those selections to generate customized game outcome probabilities.

The goal of StatifiedMLB is to go beyond simply predicting winners. The application compares its calculated probabilities with sportsbook odds to identify potential **expected value (EV)** opportunities. This allows users to see where the model's estimated probability of an outcome differs from the probability implied by the betting market.

Rather than relying on a single fixed prediction model, StatifiedMLB gives users control over the data used in each analysis, allowing them to experiment with different statistical combinations, weighting strategies, and model presets. Predictions can then be tracked against actual game results to measure accuracy and improve the system over time.

**Primary Goal:** Build an MLB analytics platform that transforms user-selected statistics into probability estimates and uses those probabilities to identify positive expected-value opportunities in MLB betting markets.
